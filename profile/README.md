# Recover My Files — restore list after a disk search

Recover My Files holds a restore list for lost folders on a PC you own: the disk search you started, the hits, and a short note the next operator can read. Extra PCs wait for their own title.

## Session Card

| Slice | What you do in Recover My Files | What remains |
|-------|------------------------|--------------|
| Arrival | Open Recover My Files and name today's restore list | A titled disk search |
| Focus | Keep only live folders on the Recover My Files board | A short hit list |
| Check | Read Recover My Files lost folders before a large restore | A confirmed restore list |
| Handoff | Mark finished folders inside Recover My Files | A note for the next operator |

## How Recover My Files Sits

Recover My Files does not replace a search on a PC you do not own, a silent undelete of someone else's folders, or a pass on a machine that is not yours. It sits beside them as a named restore list for one job: which lost folders are live, which disk search still matches your own PC, and what the next operator should read.

A first visit should be one short disk search you started on a PC you own, then the same Recover My Files restore list the next day. That is enough to see if the named hits hold.

## Traffic Light

| Signal | On the Recover My Files board | What you do |
|--------|----------------------|-------------|
| Green | Named disk search, short live restore list | Continue the same lost folders |
| Amber | Two PCs mixed on one search | Split the hits before a large change |
| Red | No title, no note, a search on a PC you do not own | Stop and name the restore list first |
| Clear | Handoff written, live searches few | Close Recover My Files and leave the restore list |

## Open Order

1. Open the last Recover My Files restore list, not a new empty disk search.
2. Confirm the PC is yours, then read the lost folders and the last handoff.
3. Finish one visible disk search inside Recover My Files on folders you own.
4. Write what changed, then close with fewer unsigned searches than you found.
5. If the list feels crowded, drop anything that belongs to a different Recover My Files job.

## After a Week

A week in Recover My Files is not a larger pile of unsigned searches. It is the same title, a shorter live hit list, and a note that still makes sense before the next disk search you started. Take finished folders off the live set so the next visit starts on the restore list that is still open.

## Sign-off

- [ ] The Recover My Files workspace name is short enough to scan
- [ ] Only folders you own sit on the restore list
- [ ] A second operator can read the search handoff
- [ ] The last Recover My Files disk search still opens after a restart
- [ ] Finished folders are off the live Recover My Files set

## Field Note

Recover My Files is easier to trust when the restore list stays on a PC you own. Name the disk search, keep the live lost folders, finish one visible pass, and write what changed. Do not search a machine you are not authorized to recover.
